
# Conformance Model

1. SCHEMA_VALID
2. PROFILE_CONFORMANT
3. VERIFIER_ACCEPTED
4. RELIED_UPON

No lower level implies a higher level, and reliance remains outside the base protocol.

Governed response-envelope validation is documented in
[`response-envelope-conformance.md`](response-envelope-conformance.md). Envelope conformance
does not establish substantive correctness or constitutional authority.
