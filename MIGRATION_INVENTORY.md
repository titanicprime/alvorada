# Migration Inventory

## Method

Statuses are `ACTIVE`, `CANDIDATE_FOR_MIGRATION`, `HISTORICAL`, `SUPERSEDED`, `GENERATED`, and
`UNCLEAR`. Classification describes repository use, not constitutional validity. Authority is
not inferred from a filename, directory, authorship, merge, correctness, consensus, or
operational success.

| Path or family | Status | Current function | Apparent authority status | Proposed layer | Proposed disposition | Dependencies | Risks | Ambiguities |
